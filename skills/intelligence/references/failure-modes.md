# 失败模式

## 通用

1. **无话题** → 追问；可对「最近 0day」先列 2–5 候选再深挖。  
2. **无 X 却写舆论** → 禁止。  
3. **编造 CVE/链接/帖子** → 禁止。  
4. **单源定论** → 安全版本区间冲突必须并列。  
5. **假精度** → 舆论份额用约数。  
6. **贩恐** → 写清前提与影响面。  
7. **PoC 教学** → 只写有无公开利用，不写步骤。  

## 安全特有

8. **KEV 滞后** → 未入 KEV ≠ 无在野；写「截至查询时 KEV 未见收录」。  
9. **标题党「全版本沦陷」** → 回查 NVD/厂商 affected。  
10. **1.x / 2.x 混淆** → fastjson 与 fastjson2 分开。  
11. **缓解当根治** → SafeMode/WAF 标为临时。  
12. **本地无关夸大** → Mac 桌面无 Java 组件则写「默认不直接命中」。  

## 技术特有

13. **评测当规格** → 第三方基准单独标注。  
14. **中英圈断层** → Gaps 标明。  
15. **未发布当已开源** → 拆清 API 可用 vs 权重/源码已放。  

## 样本

16. **水军/同质转发** → 降权，Gaps 提示。  
17. **官方沉默** → 明说。  
18. **起源在窗外** → 仍 fetch 起源线程。

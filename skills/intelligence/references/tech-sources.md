# 前沿技术情报信源优先级

## P0 · 第一方

- 官方博客、Release Notes、产品文档  
- 官方 GitHub/GitLab Release、组织账号  
- 官方 X / 账号 `from:handle`  

## P1 · 独立评测与权威榜（二手，需标注）

- 公开基准与排行（LMSYS、Artificial Analysis、厂商对测等）  
- 知名研究组技术报告  

写明「第三方评测，非官方承诺」。

## P2 · X 开发者与从业者讨论

- 用于：落地体验、价格/延迟吐槽、集成坑  
- 样本粗判阵营；不上升为规格事实  

## P3 · 科技媒体

- 时间线与传播上下文  
- 参数与日期以 P0 为准  

## 前沿技术模式采集建议

1. 官方发布帖/博客/论文页（web 或 X first-party）  
2. 关键能力、规格与时间点（官方 vs 第三方评测分开写）  
3. X Top + Latest 反应  
4. 1–2 条高质量批评/钢人线程  

## 中英圈

- 中文与英文分开检索与表述  
- 避免「全球开发者一致认为」式总结
